## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Nucleus** — A collaborative engine that enables sharing of applications and renderings for creating virtual worlds.
- **Connect** — Plugins that allow client apps to connect to Nucleus, facilitating the publication and subscription of generated worlds.
- **Kit** — A module for developers to create their extensions, applications, services, and plugins tailored for the Omniverse ecosystem.
- **Simulation** — A scalable simulation environment that allows developers to test their creations in a physically accurate world.
- **RTX Renderer** — An advanced multi-GPU renderer that leverages RTX technology for high-quality visuals.
